# Ukraińska Knajpa — redesign concept

A static, responsive, three-language website concept (Ukrainian / Polish / English).

## Preview
Open `index.html` in a browser. Internet access is required for Google Fonts; all food images are included locally in `assets/`.

## Important before publishing
- This is a visual prototype, not an official restaurant website.
- Dish descriptions are editorial sample copy. Confirm the actual menu, ingredients, allergens and availability with the restaurant.
- Prices are intentionally omitted because current prices were not verified.
- Confirm the phone number, address, opening hours, booking process and social links before launch.
- Replace the concept logo/illustrations and generated food imagery with approved brand assets if the restaurant requires them.
